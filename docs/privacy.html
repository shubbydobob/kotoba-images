1. 이 도구의 성격

sns-autopost는 운영자 본인이 자신의 SNS 계정에 학습 카드를 올리기 위해 쓰는 개인용 자동화 도구입니다. 회원가입·로그인 기능이 없으며, 운영자 외의 이용자가 이 도구를 사용할 수 없습니다.

2. 수집하는 정보

이 도구(sns-autopost)는 이용자로부터 어떠한 개인정보도 수집하지 않습니다. 방문자 분석 도구, 쿠키, 광고 추적을 사용하지 않습니다.

다만 학습 자료 받기 페이지에서 이용자가 직접 이메일 주소를 입력하는 경우에만 그 주소를 받습니다. 입력하지 않아도 자료는 모두 받을 수 있습니다.

수집 항목이메일 주소 (이용자가 직접 입력한 경우에 한함)
수집 목적새 학습 자료가 나왔을 때 알림 메일 발송. 이 목적 외에는 쓰지 않습니다
보유 기간수신 거부 요청 시 즉시 삭제. 그 전까지는 알림 발송 목적으로 보관합니다
처리 위탁입력 양식과 응답 저장은 Google Forms를 사용합니다
거부할 권리입력은 전적으로 선택입니다. 입력하지 않아도 자료 이용에 제한이 없습니다

받은 이메일 주소를 광고에 쓰거나, 다른 사람·다른 서비스에 넘기거나, 판매하지 않습니다. 삭제·열람·정정을 원하시면 아래 7번 문의 주소로 알려 주시면 즉시 처리합니다.

3. 접근하는 Google 사용자 데이터

운영자 본인이 직접 권한을 부여한 자신의 Google 계정에 대해서만 다음 범위를 사용합니다.

  • https://www.googleapis.com/auth/youtube.upload
    운영자 본인의 YouTube 채널에 영상을 업로드하는 용도로만 사용합니다. 영상을 읽거나, 수정하거나, 삭제하거나, 채널·시청 기록·구독 정보를 조회하지 않습니다.

4. 데이터 보관

  • 인증에 쓰는 토큰은 GitHub Actions의 암호화된 Secrets에 보관하며, 코드나 로그에 남기지 않습니다.
  • 업로드한 영상 파일은 업로드 후 실행 환경에서 사라집니다.
  • Google 사용자 데이터를 별도의 데이터베이스나 서버에 저장하지 않습니다.

5. 제3자 제공

Google 사용자 데이터를 다른 사람이나 다른 서비스에 넘기거나, 판매하거나, 광고·분석·AI 모델 학습 목적으로 쓰지 않습니다. sns-autopost의 Google 사용자 데이터 이용은 Google API Services User Data Policy의 제한된 사용 요건(Limited Use)을 따릅니다.

6. 권한 철회

운영자는 Google 계정 권한 페이지에서 언제든 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 업로드가 즉시 중단됩니다.
