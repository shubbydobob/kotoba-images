sns-autopost

한국어·일본어 학습 카드를 만들어 SNS에 올리는 개인용 자동화 도구

무엇을 하나요

일본 친구와 한국 친구가 각자의 언어로 대화하는 학습 카드를 데이터(YAML)로 작성하면, 이미지를 그려서 정해진 시각에 인스타그램 · 쓰레드에 올리고, 같은 내용으로 유튜브 쇼츠 영상을 만들어 올립니다. 말풍선마다 읽는 법과 번역이 붙습니다.

누가 쓰나요

운영자 본인 한 사람만 사용하는 개인 도구입니다. 회원가입이나 로그인 기능이 없고, 일반 이용자가 이 도구에 접속하거나 계정을 만들 수 없습니다.

Google 계정을 어떻게 쓰나요

  • YouTube Data API — 운영자 본인 채널에 영상을 올리는 데만 씁니다 (youtube.upload 권한).
  • Cloud Text-to-Speech API — 카드의 대사를 음성으로 바꿔 영상에 넣습니다.

다른 사람의 Google 계정 정보를 요청하거나 읽지 않습니다. 자세한 내용은 개인정보처리방침을 봐 주세요.
