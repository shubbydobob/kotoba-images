1. 적용 범위

sns-autopost는 운영자 본인이 쓰는 개인용 자동화 도구입니다. 외부에 제공하는 서비스가 아니며, 회원가입·로그인 기능이 없습니다. 이 약관은 운영자가 이 도구를 사용할 때의 조건을 적는 문서입니다.

2. 하는 일

데이터 파일로 작성한 학습 카드를 이미지·영상으로 만들어, 운영자 본인의 인스타그램 · 쓰레드 · YouTube 계정에 정해진 시각에 올립니다.

3. 콘텐츠

  • 카드와 영상에 들어가는 글은 운영자가 직접 쓰거나 퍼블릭 도메인인 문장만 사용합니다.
  • 저작권이 살아 있는 가사·문장은 사용하지 않습니다.
  • 학습 자료로 만든 내용이므로 표현이 완벽하다고 보증하지 않습니다. 틀린 부분은 수정합니다.

4. 다른 서비스의 약관

이 도구는 Instagram, Threads, YouTube의 API를 사용하며 각 서비스의 약관과 정책을 따릅니다. YouTube 업로드 기능은 YouTube 서비스 약관과 YouTube API 서비스 약관을 따릅니다.

5. 보증과 책임

이 도구는 있는 그대로 제공되며, 동작이나 결과에 대해 어떠한 보증도 하지 않습니다. 자동 게시가 실패하거나 지연되어 발생한 손해에 대해 책임지지 않습니다.

6. 변경

이 약관은 예고 없이 바뀔 수 있으며, 바뀐 내용은 이 페이지에 게시합니다.
